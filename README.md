# Story Studio

이야기 소재를 입력하면 시놉시스부터 스토리보드, 이미지·영상 프롬프트, 이미지, 나레이션까지 단계별로 제작할 수 있는 로컬 웹 애플리케이션입니다.

## 주요 기능

1. **시놉시스 생성**
   - 이야기 소재 입력
   - 약 3,000자 분량
   - 제작 용도 선택
     - 동영상 쇼츠
     - 애니메이션 웹툰
     - 실사 동영상
     - 뮤직비디오
   - 장르, 분위기, 대상 시청자 설정

2. **스토리보드 생성**
   - 시놉시스를 바탕으로 컷별 스토리보드 작성
   - 용도에 따른 추천 컷 수 제공
   - 컷 수와 연출 방향 변경 가능

3. **이미지 프롬프트 생성**
   - 스토리보드를 바탕으로 컷별 이미지 프롬프트 작성
   - 이미지 컷 수 선택
   - 화면 비율 선택
   - 시각 스타일 입력

4. **Google Flow 영상 프롬프트 생성**
   - 영상 컷 수 선택
   - 컷별 영상 길이 선택
   - 화면 비율 선택
   - 해상도 선택
   - 카메라 움직임, 조명, 인물 동작, 사운드를 포함한 프롬프트 생성

5. **이미지 생성**
   - ChatGPT 로그인 기반 이미지 생성
   - Google Flow용 프롬프트 복사
   - 생성된 이미지 확인 및 저장

6. **녹음용 나레이션 생성**
   - 나레이션 컷 수 설정
   - 컷별 길이 설정
   - 성우 유형 선택
   - 감정, 호흡, 발음 지시가 포함된 녹음 대본 생성

## 필요한 프로그램

로컬에서 생성 기능을 사용하려면 다음 프로그램이 필요합니다.

- [Node.js](https://nodejs.org/)
- [Codex CLI](https://developers.openai.com/codex/)
- ChatGPT 계정
